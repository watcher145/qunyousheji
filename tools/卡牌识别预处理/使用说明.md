# 卡牌识别预处理

把武将卡图（社区卡框架，如子子杯 732x1028）按固定区域裁剪、放大、增强，输出供 AI 视觉精读的 PNG + 识别模板。配合 AI 会话使用：**先跑本脚本，再让 AI 逐张 Read 裁剪图转写**，识别精度远高于整图直接看或传统 OCR（特殊字体、繁体、篆书都靠放大裁剪 + 逐部件核对解决）。

## 用法

命令行（AI 会话里直接跑）：

```bash
# 整个目录的卡图（推荐）
python tools/卡牌识别预处理/card_crop.py "C:\Users\25040\Downloads\某卡包目录"

# 单张图
python tools/卡牌识别预处理/card_crop.py IMG.jpg

# 难字复核：对某字所在小格再裁一版（绝对像素坐标，倍数可选）
python tools/卡牌识别预处理/card_crop.py IMG.jpg --extra shuxin=95,765,160,812,12
```

也可以把图片直接拖到 `启动.bat` 上。

输出在输入目录下的 `card_crops/<图名>/`：

| 输出 | 内容 |
|---|---|
| `<图名>_full.png` | 原图（定框架、势力、整体布局） |
| `<图名>_hp.png` | 血量条（数宝珠） |
| `<图名>_left.png` | 左侧竖列：称号（篆书）+ 名字（书法） |
| `<图名>_title.png` / `_title_bin.png` | 称号特写（灰度增强 + Otsu 二值化，逐部件核对用） |
| `<图名>_name.png` | 名字特写 |
| `<图名>_skilltext.png` | 技能描述面板（逐行转写用） |
| `<图名>_skillname.png` / `_skillname_bin.png` | 技能名框条（隶书，最易误读处，加倍放大） |
| `<图名>_footer.png` | 落款（插画/设计） |
| `<图名>_识别模板.md` | 待填模板 + 四步核验清单 |

## 识别四步核验（AI 侧必守，写在模板里）

1. **先描形后定字**：难字先客观记录结构（左右/上下）与判别性笔画，此阶段禁止出现"这是某字"的判断。
2. **候选穷举**：按部件组合列出所有常见候选字（歧义时至少 2-3 个）。
3. **判别笔画核对**：候选字互异的关键笔画逐一回图找"存在/缺失"证据。
4. **语义只做终审**：字形证据赢了但读起来不顺的候选照样定案；"像某个常用词"不构成证据。

教训实例：纾**釁** 的皿式通栏长横曾被读成 難 的隹部——"纾难"是真实常用词，语义锚定会提前终止候选搜索。

## 区域标定

预设坐标按"社区卡框架"（宽高比 ≈ 0.712，如 732×1028）用**比例**标定，同框架不同分辨率自动适配。非该框架的卡传 `--preset none` 并用 `--extra 名=x0,y0,x1,y1[,倍数]`（绝对像素）手工指定区域。

依赖：Python 3 + Pillow（`python -c "import PIL"` 能过即可）。

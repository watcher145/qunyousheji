# 无名杀 武将插画裁切器

把武将插画（展示图/原画）自动裁成无名杀标准 **350×464**，三种模式：

| 模式 | 输入 | 输出 |
|---|---|---|
| **单头将** | 一张图一个武将 | 350×464 |
| **双头将** | **一张**图里画着两个武将 | 两张单人图 + 一张拼接合体卡 |
| **两张单人图拼一张** | **两张**各自只有一个武将的图 | 一张拼接合体卡（左=第1张，右=第2张） |

人工（图形界面）和 AI（命令行）都能用。

---

## 一、图形界面用法（手动）

1. 双击 **`启动.bat`**（或命令行运行 `python 插画裁切器.py`）
2. **① 选择武将类型**：`单头将` / `双头将` / `两张单人图 → 拼成一张双将卡`
   （第三种模式会**按顺序两两配对**：第 1+2 张、第 3+4 张…，所以要按「左、右、左、右」的顺序添加图片）
3. **② 添加图片…**（可一次多选）或 **添加文件夹…**（整个目录里的图片一起加），支持 jpg / jpeg / png / webp / bmp
4. **③ 输出目录**：留空则输出到“第一张图所在目录/crops”
5. 点底部 **▶ 开始裁切**（或直接按**回车键**），完成后自动打开输出目录

勾选“同时输出标注图”会在输出目录生成 `_debug_*.jpg`：**绿框 = 裁切范围、红点 = 识别到的脸**，一眼就能核对有没有选错脸，选错了就手动裁或换图。

> **找不到“开始裁切”按钮？** 按钮固定在窗口**最底部**；把窗口拉大一点即可。窗口最小尺寸已保证按钮可见。
>
> **双击 `启动.bat` 没反应 / 提示缺少依赖？** 启动器会自动在 `py` 启动器与 PATH 里的 `python` 中**逐个探测**哪个装了 opencv-python / numpy / Pillow，用能跑的那个启动。若全都缺，按提示装依赖即可（见第五节）。

## 二、命令行用法（AI / 批量）

```bash
# 单头将：一张图裁一人（可传多张图，或直接传目录）
python 插画裁切器.py --mode single --out 输出目录 图1.jpg 图2.jpg
python 插画裁切器.py --mode single --out 输出目录 "D:/我的图集"

# 双头将：一张双人图 → 两张单人图 + 一张拼接合体卡
python 插画裁切器.py --mode dual --out 输出目录 双将图.jpg

# 两张单人图 → 拼成一张双将卡（左=第1张，右=第2张；按顺序两两配对）
python 插画裁切器.py --mode pair --out 输出目录 --name 成品名 左图.jpg 右图.jpg
python 插画裁切器.py --mode pair --out 输出目录 "D:/图集"     # 目录里按文件名顺序两两配对

# 可选参数
--debug    输出标注图 _debug_*.jpg（绿框=裁切范围，红点=识别到的脸）
--name     pair 模式的输出文件名（不含扩展名，默认「左图名_右图名」）
```

输出命名：
- 单头将：`<原图名>.jpg`
- 双头将：`<原图名>_1.jpg`（左/第一个名字）、`<原图名>_2.jpg`（右/第二个名字）、`<原图名>.jpg`（拼接合体卡）
- 拼一张：`<左图名>_<右图名>.jpg`（可用 `--name` 指定）

## 三、裁切规则（照本体统计出的构图）

| 参数 | 值 | 说明 |
|---|---|---|
| 脸心 X | 0.50 | 水平居中（**按"头"居中，见下**） |
| 脸心 Y | 0.351 | 落在上 1/3 |
| 脸宽占比 | 23.8% | 单头将 |
| 双将单人图脸宽 | 23.8% | 同上 |
| 拼接合体卡 | 两张半幅各占一半 | **每半幅各自**把脸归一化到占半幅 **45%**（≈整卡宽 22.5%，与单将卡 23.8% 对齐） |
| 输出尺寸 | 350×464 | 人物贴边时**收紧窗口**（不补边，脸会偏离中心） |

> 以上参数来自对本体 56 张 350×464 官方插画的统计（42 张可检出的脸：脸心 X 中位 0.484、Y 0.351、脸宽 0.238）。

## 四、识别逻辑与已知边界

**识别**：YuNet 深度人脸模型（`yunet.onnx`，随包携带）
1. **整图扫**：阈值 0.6（可信度高的这一遍）
2. **放大补扫**：仅当整图扫到的高分脸**不够用时**才跑（放大 2.5 倍、阈值 0.45、且要求检出 ≥3% 图宽）——小脸/侧脸靠它救回
3. 同一张脸的重复检出会**聚类合并**（防止“一张脸被当两人”）；合并时**整图扫的结果优先**
4. **分数剪枝**：置信度比最高分低 0.12 以上的检出直接丢掉 —— 举起的手 / 拳头 / 衣饰常被误检成脸，
   而且**框往往比真脸还大**，不剪掉就会靠“尺寸大”把真脸挤掉
   （实例：扬帆出海那张，手 72×93@0.78 挤掉了真脸 42×61@0.90）
5. 选脸策略：优先只从**整图扫**的检出里选（不够才用补扫的）；其中**高分脸（≥0.6）优先，其次比大小**
6. 双头将配对评分 = **置信度² × 尺寸^0.5 × 间距**，让“大而假”的框不再取胜；找不到两张分开的脸会直接报错跳过（不会拼两张一样的脸）

> 为什么补扫要“按需触发”：放大 + 低阈值在**复杂背景**（花枝、灯笼、鸟、衣纹）上会刷出大量假脸
> ——实测一张 2250px 宽的双人插画能刷出 18 张“脸”，还会挑中一张 183px 的假脸当主脸。现在改成按需触发后就稳定了。

**已知边界**（工具会给出提示，需人工把关）：
- 原图人物贴边 → 自动收紧窗口（**不镜像补边**），裁片里脸会偏离中心，日志标注“（贴边，脸未居中）”
- 原图带竖排标题/技能名/版权行文字 → 裁片里可能带字，工具不做去字（可手工裁）
- **请喂纯插画图**：如果传的是完整卡面（含卡框/技能文本框/称号），裁片会把这些也裁进去
- 原图脸太小（<6% 图宽）→ 成片是放大出来的，会偏软
- 日志出现“置信度偏低”→ 建议看 `_debug_*.jpg` 确认

> **双头将拼接**：**每一半各自把"脸"归一化到占半幅 45%**，再各自缩放到 175×464 后横向拼接。
> - 好处一：源图里两张脸一大一小时，小脸那半会被自动放大补齐 —— **成品里两张脸一样大**（不会出现"一个头大一个头小"）。
> - 好处二：两半输出尺寸相同，天然等高，**不会出现黑边**（早期版本两半各自定高、画布垫黑底，较矮那半底部会露黑块）。
> - 想调大小：改脚本顶部常量 `DUAL_HALF_FW`（0.45 ≈ 头宽占整卡 22.5%；调大=头更大更特写，调小=更全身）。
>
> **按"头"居中，不是按"脸框"居中**：YuNet 给的是**脸框**，但侧脸（尤其戴高帽 / 发髻大的）的
> "头"比脸框宽——后脑和帽子偏向脸的背面。所以裁切中心会按朝向修正：
> `偏移 = (0.5 − 鼻尖在脸框内的相对 x) × 脸宽 × 1.2`（`HEAD_TURN_K`）。
> 正面脸（鼻尖≈0.5）偏移≈0，不受影响；侧脸才生效，帽子/后脑就不会被切在边上。
>
> **不会覆盖源图**：如果输出目录就是图片所在目录、且文件名相同，工具会自动另存为 `原名_裁切.jpg`
> 并在日志里提示，源文件保持原样。

## 五、环境

需要 Python 3.8+ 与三个库：

```bash
pip install opencv-python numpy pillow
```

**注意：一台机器上可能装了多个 Python，只有装了上面三个库的那个能跑本工具。** 所以：

- 双击 `启动.bat`：会依次尝试 `py -3.12`、`py -3.13`、`py -3.11`、`py -3.10`、`py -3`，再试 PATH 里的 `python`、`python3`，用**第一个能成功 `import cv2,numpy,PIL`** 的启动；
- 手动运行时可指定解释器，例如：`py -3.12 插画裁切器.py`
- 也可以把依赖直接放到脚本同目录的 `libs/` 文件夹里（脚本会自动加入搜索路径）——适合做免安装便携包。

`yunet.onnx` 是 OpenCV 官方 YuNet 人脸检测模型（约 230KB），已随本工具携带，无需另外下载。
